## 1. 系統簡介

本系統管理萬美基金會自費醫療補助案件的完整處理流程：**收件 → 行政初審 → 家庭訪視 → 董事審核 → 核銷撥款 → 結案**，並提供結案後的關懷追蹤與案件統計分析。

### 補助類別

系統處理的四種補助類型：

| 類別 | 說明 |
|---|---|
| 自費醫療補助 | 一般自費醫療項目補助 |
| 臨終安寧自費醫療補助 | 安寧療護相關自費補助 |
| 預立醫療照護諮商補助 | 預立醫療照護諮商費用補助 |
| 醫事人員進修補助 | 醫事人員教育進修補助 |

每件案件都會產生一個唯一的「案件編號」，由系統自動編配，無法手動修改。

### 案件狀態

| 狀態 | 說明 |
|---|---|
| 審核中 | 案件在處理中（行政初審 / 家庭訪視 / 董事審核 / 核銷撥款其中之一階段） |
| 審核未通過 | 已結案，董事審核結果為不通過 |
| 待核銷 | 董事已核准，等待會計處理撥款 |
| 核銷完成 | 已結案，撥款完成 |

### 工作階段

案件依序經歷四個處理階段：

**行政初審** → **家庭訪視** → **董事審核** → **核銷撥款** → 結案

## 2. 角色與職責

系統設有 8 種使用者角色，一個帳號可同時擁有多個角色。

| 角色 | 主要職責 |
|---|---|
| 承辦人員 | 收件、建立案件、文件審核、推進行政初審 |
| 社工人員 | 家庭訪視、填寫家訪表、關懷追蹤 |
| 主管 | 監督案件進度、檢視統計、後台部分管理 |
| 會計 | 核銷階段文件審核、列印領款收據、處理撥款 |
| 董事 | 董事審核、電子簽章 |
| 董事長 | 派組、所有董事權限、後台部分管理 |
| 系統管理員 | 全部權限：帳號管理、系統設定、所有資料 |
| 志工 | 結案後的關懷追蹤紀錄 |

> 「申請人」也是一種系統內的角色，但**不參與任何畫面操作**——僅作為資料分類；申請人接受家訪、收信、領款，但不需要登入系統。

### 權限速查表

| 功能 | 可執行角色 |
|---|---|
| 新增申請案件 | 承辦人員、系統管理員 |
| 申請案件查詢 | 全部角色（顯示內容依角色而異） |
| 文件上傳/審核 | 承辦人員、系統管理員（會計於核銷階段亦可） |
| 家庭訪視表填寫 | 社工人員、承辦人員、系統管理員 |
| 派組（董事分組） | 董事長、系統管理員 |
| 董事審核 + 簽章 | 該案被派組之董事、董事長 |
| 核銷階段文件列印 | 會計、系統管理員 |
| 關懷紀錄建立 | 志工、社工人員 |
| 關懷紀錄檢視 | 志工、社工人員、主管、系統管理員 |
| 案件統計報表 | 系統管理員、主管、董事長、董事 |
| 後台管理 | 系統管理員（部分功能開放主管 / 董事長） |
| 系統參數設定 | 系統管理員 |

## 3. 登入與個人設定

### 登入

1. 開啟系統首頁
2. 輸入帳號與密碼
3. 登入後會保留所有授予的角色權限

### 個人設定

進入路徑：**首頁 → 右側快速功能 → 個人設定**

#### LINE 綁定

1. 點「**產生綁定碼**」→ 系統顯示 6 位數字綁定碼（5 分鐘內有效）
2. 點「加 LINE bot 為好友」連結（或用手機掃 QR code 加好友）
3. 在與 bot 的對話中輸入剛才的 6 位數字
4. 收到「綁定成功」回覆即完成

#### 通知接收方式

勾選「Email」和（或）「LINE」作為接收通知的方式，**至少需勾選一個**。

> 若尚未綁定 LINE，「LINE」選項會以灰色顯示無法勾選，需先完成 LINE 綁定。

## 4. 案件處理流程

### 完整流程

```
┌─────────────────────────────────────────────────────┐
│  收件                                               │
│  （承辦人員建立案件 或 申請人線上提交）              │
└─────────────────────┬───────────────────────────────┘
                      ↓
┌─────────────────────────────────────────────────────┐
│  行政初審                                           │
│  • 文件審核 / 缺件補件提醒                          │
└─────────────────────┬───────────────────────────────┘
                      ↓
┌─────────────────────────────────────────────────────┐
│  家庭訪視                                           │
│  • 社工填寫家訪表                                   │
└─────────────────────┬───────────────────────────────┘
                      ↓
┌─────────────────────────────────────────────────────┐
│  董事審核                                           │
│  • 派組 → 全員簽章 → 核定金額                        │
└─────────────────────┬───────────────────────────────┘
                      ↓
┌─────────────────────────────────────────────────────┐
│  核銷撥款                                           │
│  • 系統自動寄領款收據 PDF 給申請人                  │
│  • 會計列印歸檔文件                                 │
│  • 收到申請人寄回紙本後撥款 → 結案                  │
└─────────────────────────────────────────────────────┘
```

### 退件路徑

- 任何階段不通過 → 退回前一階段補正，或結案為「審核未通過」
- 董事審核結果為「不通過」→ 直接結案
- 核銷完成 → 結案為「核銷完成」

### 重要規則

- **案件編號**自動產生，不可手動修改
- 申請人 **Email 為必填**，因核銷階段會自動寄送領款收據
- **退回到「董事審核」之前的階段**（例如從董事審核退回家庭訪視）會自動清空：
  - 該案的董事派組紀錄
  - 全部董事的電子簽章
  - 董事共同審核意見
  
  重新推進回董事審核時視同全新，需重新派組與簽章。這是為了避免舊資料污染新一輪審查結果。

## 5. 常見操作步驟

### 5.1 承辦人員 — 建立案件

1. 首頁 → **新增申請案件**
2. 輸入身分證字號 → **查詢申請資格**（系統會檢查累積補助是否達上限、是否有未結案）
3. 通過資格檢查後，填寫資料：
   - 申請人姓名
   - **Email（必填）**
   - 申請類別（自費醫療 / 安寧 / 預立醫療諮商 / 醫事進修）
   - 申請金額
   - 案件來源（自提 / 轉介，轉介需選單位）
4. 儲存 → 案件進入「行政初審」階段
5. 切到案件詳情頁的文件分頁，上傳必備文件

### 5.2 案件查詢 / 篩選

進入路徑：**首頁 → 申請案件管理**

可用篩選條件：
- 狀態（進行中 / 結案）
- 處理階段
- 承辦人
- 申請人姓名 / 身分證（模糊比對）
- 申請日期區間

點擊任何案件列即可進入詳情頁。

### 5.3 社工人員 — 家庭訪視

案件推進到「家庭訪視」階段後：

1. 開啟案件詳情 → 切到**家庭訪視**分頁
2. 填寫評估項目：
   - 自述病情
   - 對疾病反應狀態 / 治療態度
   - 家庭互動狀況
   - 主要照顧者資訊
   - 補助需求說明
   - 訪視者建議
3. 儲存 → 推進到「董事審核」階段

### 5.4 董事長 — 派組

當案件進入「董事審核」階段，系統會依設定決定派組方式：

- **自動派組（系統參數開啟時）**：系統自動選擇目前案件最少、優先序最小的董事組別
- **手動派組（系統參數關閉時）**：董事長收到「新案件待派組」通知，需進後台手動指派一個董事組

派組完成後，**該組所有董事**會收到「您所屬組別有新案件待審」通知（Email / LINE 依個人偏好）。

### 5.5 董事 — 審選 + 簽章

被派組的董事登入後：

1. 開啟案件詳情 → 切到**董事審核**分頁
2. 輸入：
   - 核定金額
   - 審核意見
3. 儲存草稿
4. 進行**手寫電子簽章**（可用觸控或滑鼠繪製）
5. **必須全組成員都完成簽章**，案件才能推進到核銷階段
6. 若中途退回或重新指派組別，所有簽章會被清空（保護審查一致性）

### 5.6 會計 — 核銷撥款

當案件進入「核銷撥款」階段：

1. **系統會自動寄送領款收據 PDF 給申請人**（無須會計動手）
2. 會計開啟案件詳情 → 進入核銷分頁的**文件列印**區塊
3. 區塊有四顆按鈕：
   - **審核意見表**（含全部董事的電子簽章）
   - **醫療收據**（申請人已上傳的檔案）
   - **領款收據**（基金會 header + 國字大寫金額）
   - **一鍵列印全部**
4. 點任何按鈕直接叫出瀏覽器列印對話框（可實體列印或另存 PDF）
5. 等待申請人寄回填妥的紙本領款收據 → 進行實體撥款
6. 完成撥款 → 在系統按「結案」 → 案件狀態變為「核銷完成」

### 5.7 退回案件

在任何階段都可以將案件「退回」前一階段（需附備註說明）。

> ⚠️ **退回到「董事審核」之前的階段**會清空派組、簽章、審核意見。退回後重新推進回董事審核時，系統視同全新案件（重新派組、重新簽章），這是設計上的保護機制。

## 6. 後台管理

進入路徑：**首頁 → 後台管理工具**（系統管理員可見；董事長、主管會看到部分分頁）

### 主要分頁

| 分頁 | 功能 |
|---|---|
| 帳號權限管理 | 建立使用者、指派角色、停用 / 啟用帳號 |
| 文件類型管理 | 增減必備文件、設定屬於哪個階段、可否延後補件 |
| 檔案實體位置 | 設定紙本檔案櫃位的樹狀結構 |
| 範本檔案 | 維護下載區的表單範本 |
| Banner 管理 | 首頁輪播圖片的上下架 |
| 公告管理 | 首頁公告的發佈與下架 |
| 董事組別管理 | 建立董事組、指派組員、設定派組順序 |
| 轉介單位管理 | 維護合作醫院或機構名單 |
| 系統操作紀錄 | 查詢系統內所有關鍵操作的歷程 |
| 系統參數設定 | 調整系統運作的各種閾值 |

### 系統參數設定（重要參數說明）

| 參數名稱 | 說明 |
|---|---|
| 每人累積補助金額上限 | 同一申請人累積核准金額的上限（元） |
| 缺件警示天數 | 收件後超過幾天仍未補件則於首頁顯示警示 |
| 缺件提醒次數門檻 | 同案件累計寄發幾次催件 Email 後，提示承辦人考慮結案 |

| 通知派送總開關 | **必須開啟才會真的寄出 Email / LINE 通知**；關閉時事件仍會發生但不通知 |
| LINE 官方帳號 ID | 使用者個人設定頁「加好友」連結會用此值組成 |
| 公告 NEW 標籤天數 | 公告發布後顯示「NEW」紅標的天數 |
| 基金會全名 | 列印領款收據時顯示在標頭 |
| 主管機關核准立案字號 | 列印領款收據時顯示在標頭 |
| 法人登記證字號 | 列印領款收據時顯示在標頭 |
| 統一編號 | 列印領款收據時顯示在標頭 |
| 登記住址 | 列印領款收據時顯示在標頭 |
| 聯絡電話 | 列印領款收據時顯示在標頭 |
| 傳真 | 列印領款收據時顯示在標頭 |
| LINE 加入志工 QR 圖片 | 列印領款收據時顯示的 QR code 圖片路徑 |

## 7. 統計報表

### 案件統計

進入路徑：**首頁 → 案件統計**（系統管理員 / 主管 / 董事長 / 董事可見）

操作步驟：
1. 選擇日期區間（預設為本月 1 日至今天）
2. 點「查詢」
3. 畫面顯示：

   - **總覽**：通過數 / 不通過數 / 通過率 / 進行中數
   - **依案件類別**：四種補助類別各自的通過 / 不通過
   - **依承辦人**：每位承辦人的通過 / 不通過
   - **依案件來源**：自提 vs 各轉介單位
   - **依月份**：跨月趨勢（缺月份自動補 0）

4. **點任何數字**（非 0）→ 開啟視窗顯示該分類底下的案件清單，含最近一筆審核意見（可作為「為何不通過」的參考）
5. **下載 CSV**：一鍵把整份統計匯出為 Excel 相容的 CSV 檔

### 統計用途

- 哪一類別退件率偏高 → 是否需調整收件標準
- 哪位承辦人案量明顯偏多或偏少 → 調整分工
- 哪個月份收案量異常 → 追查原因

### 通過率計算規則

| 類別 | 是否計入通過率 |
|---|---|
| 通過（待核銷 + 核銷完成） | ✓ 計入 |
| 不通過（審核未通過） | ✓ 計入 |
| 進行中 | ✗ 不計入分母 |

> 進行中案件還沒有結果，若計入會稀釋通過率數字，所以系統將其獨立顯示為「進行中：X 筆（不列入統計）」。

## 8. 關懷追蹤

進入路徑：**申請案件管理 → 點選某申請人 → 切到「關懷紀錄」分頁**

### 角色權限

| 角色 | 可做動作 |
|---|---|
| 志工 / 社工人員 | 看 + 新增關懷紀錄；可編輯 / 刪除**自己**建的紀錄 |
| 系統管理員 | 看 + 刪除任何紀錄（**不能編輯他人的**） |
| 主管 | 只看，不可建立或編輯 |
| 其他角色 | **看不到此分頁** |

### 每筆紀錄欄位

- **關懷對象**（自動帶入該申請人）
- **關懷日期**（必填，預設今天）
- **關懷摘要**（必填，自由文字）
- **媒體雲端連結**（可填 0 個或多個 URL）

> ⚠️ **系統不收檔案**。圖片或影片需要先上傳到 Google Photos / Drive / YouTube 等雲端服務，再把分享連結貼進系統。

## 9. 通知功能

### 通知總開關

系統參數中有一個「**通知派送總開關**」，**必須開啟**才會真的寄出 Email 或推送 LINE 通知。

關閉時：事件仍會正常發生（業務不受影響），只是系統不會主動通知任何人。

### 系統觸發的通知事件

| 事件 | 觸發時機 | 收件人 | 管道 |
|---|---|---|---|
| 新案件待派組 | 案件推進到董事審核且為手動派組模式 | 全部董事長 | Email + LINE（依個人偏好） |
| 您所屬組別有新案件待審 | 派組完成 / 重新派組 | 該組所有董事 | Email + LINE（依個人偏好） |
| 申請通過通知（含領款收據 PDF） | 案件推進到核銷階段 | 申請人 | **僅 Email**（含 PDF 附件） |

### 個人接收偏好

每位使用者可在「個人設定 → 通知接收方式」勾選：
- Email（任何人都可選）
- LINE（需先完成 LINE 綁定才能勾）

至少需勾選一個。

### 系統通知範本

系統內建以下幾個 Email / LINE 通知範本，**可由系統管理員編輯文字內容**（主旨與內文）：

- 案件進入董事審核的通知（Email 與 LINE 各一）
- 案件派組完成的通知（Email 與 LINE 各一）
- 申請通過寄送領款收據的通知（Email）

這些範本在後台「通知管理」分頁的範本列表上會標示「**系統**」標籤，**不可改名、不可刪除、不可停用**，但內容可調整文字。

### 缺件提醒

承辦人首頁會自動顯示「未補件案件」警示：
- 收件後超過設定天數仍有必備文件未上傳的案件 → 出現在警示列表
- 系統會累計寄出的催件 Email 次數；累計達門檻次數後，系統會在首頁與案件詳情頁提示承辦人「考慮以不通過結案」

## 10. 常見問題

### Q1：案件推進到核銷後，申請人沒收到領款收據？

請依序檢查：
1. **通知派送總開關**是否開啟（後台 → 系統參數設定）
2. 申請人帳戶是否有填寫 Email
3. 請系統管理員到後台「系統操作紀錄」查詢該案的「自動寄送領款收據」紀錄狀態：
   - 顯示「已送達」→ 系統端成功，請申請人檢查垃圾信件匣
   - 顯示「失敗」→ 系統管理員可看詳細錯誤訊息排查
   - 顯示「無 Email 跳過」→ 申請人 Email 欄位空白

### Q2：我是董事，但看不到某件要審的案件？

- 確認你是否被派進該案的董事組：請董事長或系統管理員到「董事組別管理」確認組員清單
- 若該案被重新指派到別組，原組成員（包括你）就無法再看到該案，原本的簽章也會被清除

### Q3：不小心推進錯階段怎麼辦？

- 使用「**退回**」功能可回到前一階段（需附備註）
- ⚠️ 注意退回到「董事審核」之前的階段會清空所有派組與簽章
- 如果是「核銷撥款」階段不慎執行，請聯絡系統管理員協助處理

### Q4：申請人想換 Email？

兩種方式：
- **重新建立案件**時系統會自動更新申請人的 Email
- 或請系統管理員到後台「帳號權限管理」手動修改

### Q5：CSV 匯出後 Excel 開起來中文亂碼？

本系統匯出的 CSV 已加上 UTF-8 標記，Excel 應能正確識別。
若仍亂碼：請改用 Excel 的「資料 → 從文字／CSV 匯入」並選擇 UTF-8 編碼。

### Q6：退回案件後重新推進到董事審核，組員還是原本那組嗎？

**不一定**。退回會清空派組，案件回到「未派組」狀態。再次推進時：
- 若董事自動派組是開啟的 → 系統重新挑選組別（可能是別組）
- 若是關閉的 → 由董事長手動重新派組

### Q7：關懷紀錄上傳的圖片影片存在哪？

**系統不儲存任何媒體檔案**。志工 / 社工需自行把圖片影片上傳到 Google Photos、Google Drive、YouTube 等外部雲端服務，再把分享連結貼進系統的「媒體雲端連結」欄位。

### Q8：案件統計的「進行中」筆數為何不計入通過率？

進行中案件還沒有最終結果，若把它們算進通過率分母，會稀釋掉真實的通過比例。所以系統將進行中案件獨立顯示，提醒檢視者「另有 X 筆案件還在處理中尚未列入統計」。

### Q9：核銷撥款畫面的「待撥款」何時會變「已撥款」？

當會計確認實體撥款完成、按下系統內的「結案」按鈕後，案件狀態會更新為「核銷完成」，畫面上的撥款狀態 badge 會自動從黃色「待撥款」變為綠色「已撥款」。

### Q10：歷史收據 / 文件預覽為何不能下載？

為保護申請人個資，系統內所有文件預覽頁面都設計為：
- 浮水印「僅供萬美基金會申請補助使用」
- 無下載按鈕、禁止右鍵、禁止 Ctrl+P 列印
- 僅能線上檢視

若需要列印，請走「核銷撥款 → 文件列印」區塊（限會計與系統管理員）。
