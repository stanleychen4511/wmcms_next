# SMTP 電子郵件通知設定說明

## 概述

本系統的電子郵件通知功能需要透過 SMTP（Simple Mail Transfer Protocol）伺服器發送信件。  
系統管理員須在「通知管理」頁面完成 SMTP 設定後，才能使用發送通知功能。

---

## 進入設定頁面

1. 登入系統，於首頁點選「**通知管理**」
2. 在「渠道設定」區塊找到 **Email** 卡片
3. 點選右上角的開關，確認 Email 渠道已啟用（開關呈藍色）
4. 點選「**設定 SMTP**」展開設定表單

---

## 設定欄位說明

| 欄位 | 說明 | 範例 |
|------|------|------|
| **SMTP 主機** | 郵件伺服器的主機名稱或 IP 位址 | `smtp.gmail.com` |
| **連接埠** | SMTP 服務使用的通訊埠 | `587`（TLS）、`465`（SSL）、`25`（無加密） |
| **使用 SSL/TLS** | 是否啟用加密連線 | 建議開啟（使用連接埠 465 時必須開啟） |
| **帳號** | SMTP 登入帳號，通常為完整 Email 地址 | `notify@example.com` |
| **密碼** | SMTP 登入密碼或應用程式專用密碼 | `••••••••` |
| **寄件者名稱** | 收件人看到的寄件者顯示名稱 | `萬美基金會通知系統` |
| **寄件者 Email** | 信件標頭中的寄件地址 | `notify@example.com` |

> **安全說明**：密碼儲存前會經過 AES-256-CBC 加密，不會以明文形式保存於資料庫。

## 各郵件服務商設定參考

### Gmail

> **注意**：Gmail 需要啟用「兩步驟驗證」並使用「**應用程式密碼**」，不可直接使用 Google 帳號密碼。

| 欄位 | 值 |
|------|-----|
| SMTP 主機 | `smtp.gmail.com` |
| 連接埠 | `587` |
| SSL/TLS | 關閉（使用 STARTTLS） |
| 帳號 | 您的 Gmail 地址 |
| 密碼 | Google 應用程式密碼（16 碼） |

**取得 Gmail 應用程式密碼步驟：**
1. 前往 [Google 帳戶安全性設定](https://myaccount.google.com/security)
2. 確認已開啟「兩步驟驗證」
3. 搜尋「應用程式密碼」
4. 選擇「郵件」及裝置類型，產生 16 碼密碼
5. 將此密碼填入系統的「密碼」欄位

| 密碼 | 對應帳號密碼 |

## 連接埠與加密選擇指引

| 連接埠 | 加密方式 | 說明 |
|--------|----------|------|
| `25` | 無 / STARTTLS | 伺服器對伺服器傳輸，多數 ISP 會封鎖此埠 |
| `465` | SSL/TLS（隱式） | 舊式 SSL 加密，連線建立時即加密，需開啟 SSL/TLS 開關 |
| `587` | STARTTLS（顯式） | 現代主流選擇，連線後升級為加密，**建議優先使用** |

---

## 儲存與測試

1. 填寫完所有欄位後，點選「**儲存設定**」
2. 系統會顯示「✓ SMTP 設定已儲存」確認訊息
3. 前往任一申請案件的「行政初審」頁面，點選「**發送通知**」進行實際測試
4. 若發送失敗，錯誤訊息會顯示在發送結果區塊，請依錯誤內容調整設定

## 常見問題排除

### 發送失敗：`Connection refused` / `ECONNREFUSED`
- 確認 **SMTP 主機**名稱或 IP 位址正確
- 確認 **連接埠**填寫正確，並且防火牆未封鎖該埠
- 若為內部伺服器，確認應用程式伺服器與郵件伺服器之間的網路連通性

### 發送失敗：`Invalid login` / `Authentication failed`
- 確認帳號與密碼正確
- Gmail / Yahoo 使用者請確認使用的是**應用程式密碼**，而非一般帳號密碼
- 確認帳號未被鎖定或停用

### 發送失敗：`Certificate error` / `TLS handshake failed`
- 若伺服器使用自簽憑證，請洽系統管理員調整伺服器端設定
- 嘗試切換 SSL/TLS 開關狀態（開啟或關閉）

### 信件被標記為垃圾郵件
- 確認**寄件者 Email** 與 **SMTP 帳號**使用相同網域
- 請 DNS 管理員設定 SPF、DKIM、DMARC 記錄以提升信件可信度
- 避免使用 `noreply@gmail.com` 等非本機構擁有的地址作為寄件者

### 連接埠 587 連線逾時
- 部分網路環境會封鎖 587 埠，嘗試改用 **465**（SSL/TLS 開啟）
- 確認主機防火牆允許對外連線到目標 SMTP 伺服器

---

## 注意事項

- SMTP 設定屬於系統層級設定，**僅限系統管理員**操作
- 修改設定後，新設定立即生效，舊有的通知紀錄不受影響
- 若暫時不使用 Email 通知，可在渠道設定中關閉 Email 開關，而無需刪除 SMTP 設定
- 請勿在設定中使用個人私人信箱，建議使用專屬的系統通知信箱帳號
