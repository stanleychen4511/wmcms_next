### #12 核銷撥款 —— **重大重構（4 層審核）**　🟡
**需求細節（doc3 全文）**

> 多層審核流程，每層配 **【檢核】【送出】【退件】** 按鈕；每層都看得到「累計補助金額 vs 核定金額」。

**個管師**
- 確認輸入第 N 次使用金額（例 5 萬）
- 產生並寄送領款收據
- 申請人寄回紙本
- 個管師確認並掃描上傳（累積使用金額）
- 【檢核】「請確認線上/紙本文件是否繳交齊全」
- 【送出】至主管

**部門主管**
- 【檢核】「請確認線上/紙本文件是否繳交齊全」
- 無誤【送出】至會計；有誤【退件】（必填退件原因）

**會計**
- 【檢核】董事審核意見表 2 份
- 【檢核】醫療單據與領款收據金額核對
- 【檢核】已設定銀行補助款
- 無誤【送出】至執行長；有誤【退件】

**執行長**
- 【通過】申請表、家訪、審核意見表確認
- 【完成】已核准發放（觸發通知會計、主管、個管師、申請人）
- 有誤【退件】

**累積規則**
- 累積使用金額 = 核定金額 → 結案（每層都看得到結案狀態）

**現況差距**
- 目前只有「個管師建立 disbursement」單層；缺主管 / 會計 / 執行長 3 層 + 退件機制 + 寄送收據 + 紙本回收 + 累計顯示。

**待做（高工作量）**
1. DB：`payment_disbursements` 加 `review_stage CHAR(1)`（'1'=officer→supervisor、'2'=supervisor→accountant、'3'=accountant→executive、'4'=executive→done）+ `rejected_reason TEXT` + `rejected_at TIMESTAMP` + `executive_user_id`、`accountant_user_id`、`supervisor_user_id`。
2. server actions：`advanceDisbursementStage`、`rejectDisbursementStage`，含 role gate。
3. UI：`DisbursementPanel` 改為多角色視圖，依使用者角色顯示對應的【檢核】按鈕。
4. 通知：完成時觸發 `notification_logs` 對 4 角色 + 申請人（email / LINE）。

**待客戶確認**：執行長角色是否就是 `chairman`？還是需要新增 `executive` 角色？
